#HR analytics dashboard:-

Overview: 
          Interactive Tableau dashboard analyzing employee attrition with KPIs, filters, and visualizations to identify turnover trends and support data-driven HR decisions.
          
Tools used: 
          - Tableau
          - Excel 
          
Features: 
          - Employee attrition analysis
          - Filters
          - KPI cards
          - Department analysis
          - Job role
          - Age group
          - Education field insights
